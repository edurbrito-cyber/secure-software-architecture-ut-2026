== Course workflow

This repository is the official submission location for the team.

* Invite all team members as collaborators.
* Invite the instructors as collaborators.
* Commit regularly with meaningful messages.
* Use issues or a simple project board to track tasks, risks, and feedback.
* Keep generated diagram exports together with editable sources.
* Do not commit secrets, credentials, private keys, or personal data.

At checkpoints, instructors review the state of this repository at the deadline.
